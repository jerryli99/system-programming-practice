3. Explain what effect the following macro has on its arguments. You may assume
that the arguments have the same type.

#define M(x,y) ((x)^=(y), (y)^=(x), (x)^=(y))

Answer:
The macro is doing variable swaps.

First, x ^= y.
We store the (x_original ^ y_original) in x_new. The value 
y_original after xor is unchanged.

Second, y ^= x. 
We store (y_original ^ (x_original ^ y_original)) in y_new. 
The value x_new still holds (x_original ^ y_original) from previous. 
So, y_new = (y_original ^ (x_original ^ y_original)) = x_original.

Third, x ^= y. 
(x_new ^ y_new) 
= (x_original ^ y_original) ^ (y_original ^ (x_original ^ y_original))
= (x_original ^ y_original) ^ x_original
= y_original

say in binary 
x = 0101, y = 0011

x ^= y => x = 0101 ^ 0011 = 0110
y ^= x => y = 0011 ^ 0110 = 0101
x ^= y => x = 0110 ^ 0101 = 0011
